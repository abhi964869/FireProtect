The dashboard didn’t load

The page reached the server, but the application code did not start. That usually means a script file is missing from this deployment.

The backend itself may be perfectly healthy — check /api/health. If that returns "status":"ok", only the dashboard build is at fault.

Try a hard refresh first (Ctrl+Shift+R, or Cmd+Shift+R). If it persists, open your browser’s developer console — a red 404 there names the file that is missing.
